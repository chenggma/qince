# 亲测 QinCe

亲属性别推断模型。输入一个称呼，输出这位亲属的性别，并出具一份带完整论证的鉴定报告。

![准确率](https://img.shields.io/badge/准确率-100%25-BE2A1D) ![参数量](https://img.shields.io/badge/参数量-0-17201D) ![依赖](https://img.shields.io/badge/依赖-无-17201D) ![License](https://img.shields.io/badge/license-MIT-17201D)

在线体验：<https://chenggma.github.io/qince/>

## 它能做什么

- 判断爸爸、妈妈、爷爷、奶奶、姥姥、姥爷等全家人的性别。
- 支持带前缀的称呼：我的二舅、大表哥、干妈、后爸。
- 支持英文：grandma、father-in-law、great-great-grandfather。
- 每次鉴定出具一份报告，包含检材信息、结论和六项证据。
- 全部在浏览器本地运行，输入的内容不会上传。

## 鉴定报告里有什么

| 证据 | 内容 |
| --- | --- |
| 称谓定义 | 这个称呼在亲属称谓里的定义 |
| 关系链推导 | 从“你”出发一步步走到这位亲属，逐环列出性别 |
| 备择假设检验 | 假设性别相反，推出应该用哪个称呼，再排除 |
| 重复性检验 | 对同一称呼实际重复推断 1,000 次 |
| 同义称呼交叉验证 | 用指向同一位亲属的其他称呼逐个验证 |
| 字形分析 | 检查“女”“父”“男”等偏旁。仅记录，不采信 |

## 工作原理

亲测没有神经网络，没有 GPU，参数量是 0。全部模型是 `model.js` 里的一张对照表。

1. 清洗输入，拆出“二”“小”“表”“干”这类不影响性别的前缀。
2. 查表。每个称呼对应一条关系链，比如“舅妈”是“母亲的兄弟的妻子”。
3. 看关系链的最后一环。“妻子”是女性，所以舅妈是女性。
4. 称呼本身不带性别时，模型拒答。

```js
const QinCe = require('./model.js');

QinCe.predict('我的二舅妈');
// { status: 'ok', term: '二舅妈', chain: ['母亲', '兄弟', '妻子'], gender: '女', ... }

QinCe.predict('cousin');
// { status: 'ambiguous', reason: '英语的 cousin 不区分男女，也不区分堂表。', ... }
```

## 已知局限

- **cousin**：英语里不分男女，属于本领域的开放问题。模型拒答。
- **弟妹**：可能是弟弟的妻子，也可能是弟弟和妹妹。模型拒答。
- **爱人、对象、配偶**：信息不足。模型拒答。
- **你本人**：不支持。建议询问家人。
- 准确率 100% 指模型给出结论时的准确率。它有权不给结论。

## 本地运行

没有构建步骤，没有依赖。直接打开 `index.html`，或者：

```bash
python3 -m http.server 8000
```
